The class is optional inside .mdst-ui. A bare <input type="text"> there gets the same styles. Variants still need their modifier (.mdst-input--borderless), which works without .mdst-input.

Usage
<!-- Text input -->
<input type="text" class="mdst-input" placeholder="Enter text" />

<!-- Any text-like type: email, number, search, tel, url -->
<input type="email" class="mdst-input" placeholder="you@example.com" />

<!-- Invalid -->
<input type="email" class="mdst-input" aria-invalid="true" />

<!-- Textarea -->
<textarea class="mdst-input" placeholder="Write something..."></textarea>

<!-- Disabled -->
<input type="text" class="mdst-input" disabled />
