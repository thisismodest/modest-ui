Basic
Class Example
.mdst-input
States
Attribute Example
step="25"
disabled

The class is optional inside .mdst-ui. A bare <input type="range"> there gets the same styles.

Usage
<!-- Basic range -->
<input type="range" class="mdst-input" min="0" max="100" value="50" />

<!-- With steps -->
<input type="range" class="mdst-input" min="0" max="100" value="25" step="25" />

<!-- Disabled -->
<input type="range" class="mdst-input" min="0" max="100" value="75" disabled />
