Tones
Class Example
.mdst-danger
3 Failed 30%
.mdst-success
3 Paid 100%
.mdst-warning
3 Pending 60%
.mdst-info
3 Draft 45%

Info uses the text colour unless you set --mdst-color-info. A tone colours only the element it's on, not the elements inside it, so a close button inside a danger banner stays a plain button.

Usage
<!-- One class, any component -->
<button class="mdst-danger">Delete</button>
<span class="mdst-badge mdst-success">3</span>
<span class="mdst-tag mdst-tag--subtle mdst-warning">Pending</span>
<div class="mdst-banner mdst-info">…</div>
<progress class="mdst-danger" value="30" max="100"></progress>

<!-- Combines with each component's variants -->
<button class="mdst-button--solid mdst-danger">Delete</button>

/* Your own tone */
.brand { --mdst-tone: rebeccapurple; }
