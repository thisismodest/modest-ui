Every HTML element, rendered inside .mdst-ui with no classes. The last column comes from the stylesheet that's loaded, checked when the page opens, so it's always current:

  • Styled a modest-ui rule styles it.
  • Reset only the reset touches it (beyond the margin and box-sizing reset every element gets).
  • Spacing the elements inside it are spaced apart.
  • Default the browser's own styles.
